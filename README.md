# JWT-Role-Based-Access-CRUD-Product-Spring-Boot
JWT Role-Based Access CRUD Product – Spring Boot
A Spring Boot REST API implementing JWT Authentication, Role-Based Authorization, and CRUD operations for product management using MySQL.

Features

✅ User Registration & Login

🔐 JWT Authentication

👥 Role-Based Authorization (ROLE_ADMIN, ROLE_USER)

🔄 Secure CRUD Operations

🗄️ MySQL Database Integration

🧩 Clean Layered Architecture

⚙ Spring Security + JPA + Hibernate

🛠 Tech Stack

Java 21

Spring Boot 3.x

Spring Security

JWT (JSON Web Token)

MySQL

Hibernate / JPA

Maven
